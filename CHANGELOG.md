# Changelog

Notable changes to Headroom. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added

- Tray app for macOS, Windows and Linux with one pinned agent shown in the bar.
- First-run screen that detects installed agents and asks which to track.
- Readers for Claude Code, Codex, Gemini CLI, Antigravity, Kimi and DeepSeek.
- Pace line showing whether usage will outlast the current window.
- Optional Claude limit percentages read from Anthropic.
- One silent notification at 90% of a limit.
