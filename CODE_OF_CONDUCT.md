# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and anywhere else the project is represented.

## Reporting

If someone's behaviour is a problem, contact the maintainers privately through the contact details on the repository owner's GitHub profile. Reports are kept confidential. Maintainers may edit or remove comments, and may warn or ban contributors whose behaviour breaks this code.
